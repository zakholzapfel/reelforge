ReelForge brings supported playlist and website imports, date evidence review, video/audio downloading, merging, naming, and delivery into one local app.

## Downloads

- **Apple Silicon Mac:** ReelForge-0.5.0-macOS-arm64.dmg
- **Intel Mac:** ReelForge-0.5.0-macOS-x86_64.dmg
- **Windows:** ReelForge-0.5.0-Windows-Setup.exe

Python, FFmpeg, ffprobe, and Deno are included. No subscription, API key, Python installation, or command-line setup is required to use the native app. Windows may need internet access to install Microsoft's WebView2 runtime during setup.

## Install on Mac

Quit an existing ReelForge instance, open the DMG, drag ReelForge into Applications, and launch the new copy from Applications. If macOS blocks the first launch, follow [Apple's Privacy & Security → Open Anyway instructions](https://support.apple.com/102445) for a download you trust. Keep Gatekeeper enabled. This release uses no paid Developer ID signing or Apple notarization.

The app's queue and saved reviews live separately under `~/.reelforge`. Run one instance at a time.

## Validation

The Apple Silicon Mac app was installed from its DMG and tested by the project owner, including playlist downloads, audio playback, output naming, and reopening the app. Both Mac builds and the Windows build passed their automated packaged-app checks. Those checks exercise local API startup/shutdown and bundled Deno, H.264/AAC encoding, and ffprobe with the system PATH cleared. The source test suite passed.

**Intel Mac and Windows are preview builds pending hands-on installation/UI testing.** Please report the platform, app version, and any error text when reporting a problem.

## Scope

ReelForge prepares local files for Plex, ErsatzTV, Fieldstation42, Jellyfin, or another library. It does not configure those applications. Date research uses titles, optional descriptions, imported references, and your reviews; it does not watch videos or perform autonomous web research, OCR, or transcription.
